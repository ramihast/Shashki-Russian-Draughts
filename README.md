# ♟️ Shashki — Russian Draughts

A modern, interactive implementation of **Russian Draughts (Shashki)** built with HTML, CSS, and JavaScript.

Play against a friend on the same device or challenge the computer with three difficulty levels. Designed with a responsive interface, elegant dark aesthetics, and smooth animations.

## 🌐 Live Demo

**[Play Shashki Online](https://ramihast.github.io/Shashki-Russian-Draughts/)**

## ✨ Features

- **Two Game Modes**
  - Two Players — Play locally with a friend.
  - Single Player — Challenge the computer.

- **Three AI Difficulty Levels**
  - Easy
  - Medium
  - Hard — Uses Negamax and Alpha-Beta pruning.

- **Russian Draughts Rules**
  - Mandatory captures.
  - Multiple capture sequences.
  - Flying kings.
  - Immediate king promotion during captures.
  - Draw detection.

- **Interactive Gameplay**
  - Smooth piece movements and animations.
  - Move highlighting and capture indicators.
  - Undo and restart functionality.
  - Turn indicators and captured-piece counters.

- **User Experience**
  - Persian and English language support.
  - Responsive design for desktop and mobile.
  - Optional sound effects.
  - Toggleable board coordinates.
  - Built-in game instructions.

## 🛠️ Technologies

- HTML5
- CSS3
